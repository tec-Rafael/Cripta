# Javali — extração do GIF de referência
Fonte: https://img.itch.zone/aW1nLzI5MzY5MDA0LmdpZg==/original/MBqMms.gif

Idle.png, Run.png e Strike.png: 24 quadros por folha, cada quadro com 192 × 192 px. As sequências seguem os três exemplos da esquerda para a direita no GIF; os nomes descrevem a leitura visual dos movimentos. Badge.png: emblema separado, com transparência.

Os pixels de cor foram preservados; a transparência foi reconstruída a partir do fundo do GIF promocional. Não são os arquivos-fonte oficiais e os contornos podem conter pequenas diferenças de recorte. reference.gif preserva a referência original; extract.ps1 reproduz a extração.
