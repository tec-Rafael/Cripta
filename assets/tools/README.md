# Shovel concept

`shovel-concept-v1.png` is a transparent PNG concept generated with the built-in image tool. Only the image was requested; it is not integrated into inventory or gameplay. This is a newly generated asset, not an official Tiny Swords sprite.

References: the project's original Tool_04.png (pickaxe), Tool_02.png (axe) and Tool_01.png (hammer).

Prompt: Create one shovel inventory icon in the same compact diagonal composition and pixel-art tool family as the reference tools. Keep a short dark brown wooden handle with tan highlights, a cool desaturated silver-blue spade blade and socket, dark navy-charcoal outlines, chunky pixel clusters and a limited flat palette. Use a simple rounded-point digging blade with stepped pixel edges, no modern D grip, red plastic, ornament, scenery, UI frame or text. Center the single object on a genuinely transparent square canvas, with generous padding and no glow or ground shadow. Preserve the low-resolution appearance when enlarged; no smoothing, vector curves, blur or glossy 3D rendering.
